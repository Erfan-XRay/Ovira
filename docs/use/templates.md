# Templates

A template is a ready plan: traffic, duration, devices, speed and groups. Create one for each plan you sell, then pick it when you create or renew a client. This page covers creating templates, using them and selling from them only.

## Create a template

Owners open **Templates** in the menu and press **New template**. Give it a **Name** and set the plan: traffic, days, devices, speed and groups. Days can count from creation or from the first connection. **Order** sets where it appears in lists, lower numbers first. Turn **Available** off to hide a template without deleting it.

Each template shows how many clients were created from it, and a button lists them.

## Use a template

- When you create a client, choose the **Template**. It fills the plan fields once, and you can still change them. Changing the template later does not touch existing clients.
- **Renew…** with a template adds its days and traffic to a client.
- On the clients list, select clients and choose **Apply template…** to write the template's plan onto all of them. Used traffic is kept.

Deleting a template does not change the clients made from it.

## Sell from templates only

Reseller accounts can be limited to templates. On the account, choose the **Allowed templates**, and turn on **Sell from templates only**. The reseller then creates and renews clients only from those templates, and the plan fields are fixed. See [Roles and resellers](/use/resellers).
