# Smart DNS

Smart DNS فقط با عوض کردن DNS دستگاه، به کاربر اجازه می‌دهد به سرویس‌هایی برسد که IP ایران را می‌بندند، مثل لانچر بازی‌ها، ابزارهای برنامه‌نویسی و سرویس‌های هوش مصنوعی. برنامه و تونل لازم نیست. این صفحه ساخت اینباند، فهرست دامنه‌ها و ثبت IP توسط کاربر را توضیح می‌دهد.

## به چه کاری می‌آید

- بازی‌ها، کنسول‌ها و لانچرهایی که IP ایران را نمی‌پذیرند.
- ابزارهای برنامه‌نویسی و سرویس‌های هوش مصنوعی با همین مشکل.
- مشتری‌هایی که هیچ برنامه‌ای نمی‌خواهند.

فقط تحریم را دور می‌زند. سایت‌های فیلترشده مثل یوتیوب یا اینستاگرام با آن باز نمی‌شوند. ترافیک Smart DNS از حجم کاربر کم می‌شود.

## ساخت اینباند

1. **اینباندها** را باز کنید و **اینباند جدید** را بزنید.
2. **Smart DNS** را انتخاب کنید. بعد از ساخته شدن اینباند، پروتکل قابل تغییر نیست.
3. یک **نام** بدهید و **فهرست دامنه‌ها**ی دلخواه را روشن کنید.
4. زیر **دسترسی**، گروه‌ها و کاربرانی را که آن را می‌گیرند انتخاب کنید و **ساخت** را بزنید.
5. در **نودها**، روی کارت نود مقصد، از جمله **همین سرور**، **اتصال اینباند** را بزنید.

Smart DNS روی پورت ۵۳ به پرسش‌های DNS جواب می‌دهد و ترافیک وب را روی پورت‌های ۸۰ و ۴۴۳ سرور عبور می‌دهد. اگر اینباند دیگری یا خود پنل از یکی از این پورت‌ها استفاده کند، جلوی آن را می‌گیرد و پنل می‌گوید کدام. روی نودها و روی سرور خود پنل اجرا می‌شود و شبکهٔ تونل ندارد.

## فهرست دامنه‌ها

فقط دامنه‌های فهرست‌های روشن از این سرور عبور می‌کنند. بقیهٔ سایت‌ها جواب معمول خود را می‌گیرند.

| فهرست | چه چیزی را پوشش می‌دهد |
|---|---|
| **بازی** | لانچرها، فروشگاه‌ها و ناشران. |
| **برنامه‌نویسی** | ابزارهای توسعه، Docker، JetBrains، GitLab، دانلود SDK. |
| **هوش مصنوعی** | ChatGPT، Gemini، Claude و ابزارهای مشابه. |
| **عمومی** | سرویس‌های طراحی، کار و آموزش. |
| **سرورهای دانلود** | شبکه‌های دانلود بازی و درایور. کل دانلودها از نود عبور می‌کنند. |
| **گسترده (کل شرکت‌ها)** | همهٔ ترافیک شرکت‌های بزرگ. می‌تواند ترافیک زیادی مصرف کند. اگر لازم نیست خاموش بگذارید. |

می‌توانید دامنه‌های یک فهرست را تک‌به‌تک انتخاب کنید، **دامنه‌های اضافه** بدهید و دامنه‌هایی را در **هرگز عبور داده نشوند** بگذارید. **تعداد IP برای هر کاربر** مشخص می‌کند هر کاربر چند IP می‌تواند ثبت کند.

## کاربر چه می‌کند

صفحهٔ کاربر بخش **Smart DNS** دارد.

1. DNS نشان‌داده‌شده را به‌عنوان DNS دستگاه یا شبکهٔ Wi-Fi وارد کند. صفحه راهنمای اندروید، آیفون و آیپد، ویندوز، پلی‌استیشن و ایکس‌باکس و مرورگر دارد.
2. **ثبت این IP** را بزند. Smart DNS فقط به IPهای ثبت‌شده جواب می‌دهد، پس هر وقت IP عوض شد، مثلاً در شبکهٔ جدید، دوباره ثبت کند. میان‌برهای یک‌لمسی اختیاری این کار را خودکار می‌کنند.

اگر VPN روشن است اول آن را خاموش کند. صفحه اتصال را بررسی می‌کند و می‌گوید دستگاه از Smart DNS استفاده می‌کند یا نه.
