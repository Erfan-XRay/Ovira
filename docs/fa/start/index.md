# شروع کار

اویرا یک پنل وب برای اجرای سرورهای VPN است. پنل کاربران، پلن‌ها و تنظیمات را نگه می‌دارد. سرورهایی که ترافیک را عبور می‌دهند [نود](/fa/reference/glossary) نام دارند و یک سرور می‌تواند هم پنل باشد و هم نود. این بخش شما را از یک سرور لینوکس خالی به یک کاربر متصل می‌رساند.

## چه چیزهایی لازم دارید

- سروری با Debian، Ubuntu، AlmaLinux، Rocky Linux یا CentOS Stream، با معماری amd64 یا arm64 و systemd.
- دسترسی root و یک آدرس IPv4 عمومی.
- دسترسی HTTPS خروجی از سرور، تا نصب‌کننده بتواند اویرا را دانلود کند و پنل بعداً بتواند به‌روزرسانی‌ها را بررسی کند.
- یک پورت TCP برای پنل (نصب‌کننده `2053` را پیشنهاد می‌دهد) و پورت اینباندهایی که بعداً می‌سازید. نصب‌کننده پورت‌های خودش را در `ufw` یا `firewalld` باز می‌کند، به شرطی که یکی از آن‌ها فعال باشد. فایروال شرکت میزبان را خودتان باید باز کنید.
- اختیاری: دامنه‌ای که رکورد A آن به سرور اشاره کند. بدون دامنه، پنل برای HTTPS از آی‌پی سرور استفاده می‌کند.

نود، سرور دومی است که پنل کنترلش می‌کند. برای شروع به آن نیازی ندارید، چون سرور خود پنل هم می‌تواند اینباند اجرا کند.

## ترتیب قدم‌های اول

1. [پنل را نصب کنید](/fa/start/install-panel). یک دستور، چند سؤال و یک آدرس و رمز چاپ‌شده.
2. [برای اولین بار وارد شوید](/fa/start/first-sign-in). آدرس را بررسی کنید و ورود دومرحله‌ای را روشن کنید.
3. اگر HTTPS را رد کرده‌اید یا گواهی صادر نشد، [HTTPS را تنظیم کنید](/fa/start/https).
4. برای سرورهای بیشتر [یک نود اضافه کنید](/fa/start/add-node)، یا [همین سرور را به‌عنوان نود](/fa/start/same-server) نگه دارید.
5. [اولین کاربر را بسازید](/fa/start/first-client). یک اینباند، یک کاربر، یک لینک و یک اتصال کارکرده.

صفحه‌های بعدی دربارهٔ [به‌روزرسانی](/fa/start/update)، [انتقال پنل به سرور جدید](/fa/start/move-server) و [حذف اویرا](/fa/start/uninstall) هستند.
