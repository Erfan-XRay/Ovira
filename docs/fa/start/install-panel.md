# نصب پنل

پنل با یک دستور نصب می‌شود که چهار سؤال کوتاه می‌پرسد. نصب‌کننده هیچ اینباند و هیچ کاربری نمی‌سازد؛ آن‌ها را بعداً در پنل می‌سازید. این صفحه دستور، سؤال‌ها، گزینه‌های نصب بدون پرسش و آنچه روی سرور ساخته می‌شود را توضیح می‌دهد.

## اجرای نصب‌کننده

با root وارد شوید و این دستور را بزنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/Ovira/main/install.sh)
```

برای پذیرفتن پیش‌فرض هر سؤال Enter بزنید. نصب‌کننده به این ترتیب می‌پرسد:

| سؤال | پیش‌فرض | چه کار می‌کند |
|---|---|---|
| **Panel port** (پورت پنل) | `2053` | پورت TCP که پنل روی آن گوش می‌دهد. اگر پورت در حال استفاده باشد، نصب‌کننده متوقف می‌شود. |
| **Use this server as a node too?** (این سرور نود هم باشد؟) | بله | بله: سرور اینباند هم اجرا می‌کند و در بخش **نودها** با نام **همین سرور** دیده می‌شود. نه: فقط پنل، و نودها را روی سرورهای دیگر [اضافه می‌کنید](/fa/start/add-node). بعداً هم می‌شود عوضش کرد؛ [همین سرور به‌عنوان نود](/fa/start/same-server) را ببینید. |
| HTTPS | آی‌پی سرور | گواهی Let's Encrypt برای دامنه، برای آی‌پی سرور، یا بدون گواهی. [HTTPS برای پنل](/fa/start/https) را ببینید. |
| ایمیل برای اطلاع‌رسانی گواهی | خالی | اختیاری. Let's Encrypt فقط وقتی گواهی نیاز به رسیدگی داشته باشد به آن پیام می‌دهد. |

اگر «بدون HTTPS» را انتخاب کنید، سؤال ایمیل پرسیده نمی‌شود. پیش از نصب، نصب‌کننده خلاصه‌ای نشان می‌دهد و می‌پرسد **Start installation?**.

در پایان کارتی چاپ می‌شود با آدرس پنل، نام کاربری `admin` و یک رمز تصادفی:

```text
Username   admin
Panel address (open it in your browser)
https://203.0.113.10:2053/k3x9qa7bd1/
Password (shown once; change it in the panel)
Zp8...
```

رمز فقط یک بار نشان داده می‌شود. آدرس به یک مسیر مخفی تصادفی ختم می‌شود و پنل فقط زیر همین مسیر پاسخ می‌دهد. پیش از بستن ترمینال هر دو را کپی کنید. اگر گم شدند، [صفحهٔ اولین ورود](/fa/start/first-sign-in) راه بازیابی را نشان می‌دهد.

::: warning
اگر صدور گواهی انجام نشود، نصب‌کننده متوقف نمی‌شود. پنل روی HTTP ساده بالا می‌آید و آدرس با `http://` شروع می‌شود. تا وقتی با [`ovira ssl`](/fa/start/https) مشکل را حل نکنید، رمزها بدون رمزنگاری در شبکه جابه‌جا می‌شوند.
:::

## نصب بدون پرسش

هر جواب را می‌شود به‌صورت گزینه داد. با `--yes` نصب‌کننده چیزی نمی‌پرسد و از گزینه‌ها و پیش‌فرض‌ها استفاده می‌کند:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/Ovira/main/install.sh) --yes \
  --port 8443 --ssl domain --domain panel.example.com --email you@example.com
```

| گزینه | چه کار می‌کند |
|---|---|
| `--port N` | پورت پنل. |
| `--local-node` | این سرور نود هم هست (پیش‌فرض). |
| `--no-local-node` | فقط پنل. |
| `--ssl domain`، `--ssl ip`، `--ssl none` | روش HTTPS پنل. در حالت بدون پرسش، پیش‌فرض `ip` است. |
| `--domain NAME`، `--email ADDRESS` | دامنه و ایمیل اطلاع‌رسانی برای `--ssl domain`. |
| `--user NAME` | نام اولین حساب. پیش‌فرض `admin`. |
| `--beta` | به‌جای نسخهٔ پایدار، جدیدترین بتا نصب شود. |
| `--binary FILE` | از فایلی که خودتان دانلود کرده‌اید استفاده کند. |
| `--fresh` | بعد از حذفی که داده را نگه داشته، از صفر شروع کند. |
| `--yes` | چیزی نپرسد. |

گزینه‌های `--udp-port`، `--tcp-port` و `--tcp` از نسخه‌های قدیمی هنوز پذیرفته می‌شوند ولی نادیده گرفته می‌شوند. اینباندها و پورت‌هایشان را در پنل تعیین می‌کنید.

## نصب‌کننده چه می‌کند

1. سیستم (Debian، Ubuntu، AlmaLinux، Rocky یا CentOS Stream)، دسترسی root و systemd را بررسی می‌کند.
2. بسته‌های لازم را نصب می‌کند. اگر سرور نود هم باشد، شامل OpenVPN نسخهٔ ۲٫۵ یا بالاتر؛ در سیستم‌های مبتنی بر Debian اگر OpenVPN قدیمی باشد، مخزن جامعهٔ OpenVPN را اضافه می‌کند.
3. نسخه را از گیت‌هاب می‌گیرد، و اگر گیت‌هاب کند یا مسدود باشد از میرور اویرا. دانلود را با امضای نسخه و checksum بررسی می‌کند و اگر نخواند، متوقف می‌شود.
4. سرویس `ovira` را می‌سازد و پنل را اجرا می‌کند. هر اینباندی که بعداً بسازید سرویس خودش را دارد.
5. اگر سرور نود باشد IPv4 forwarding را روشن می‌کند، و اگر `ufw` یا `firewalld` فعال باشد پورت پنل را در آن باز می‌کند.
6. گواهی HTTPS انتخابی را درخواست می‌کند.
7. دستور `ovira` را روی سرور باقی می‌گذارد.

فایل‌هایی که ممکن است بعداً لازم شوند:

| مسیر | محتوا |
|---|---|
| `/usr/local/bin/ovira` | برنامه و دستور `ovira`. |
| `/etc/ovira/config.json` | پورت پنل، مسیر مخفی، مسیر اشتراک و فایل‌های گواهی. |
| `/var/lib/ovira` | پایگاه داده: کاربران، اینباندها، نودها، گواهی‌ها، تنظیمات. |
| `/var/log/ovira-install.log` | گزارش نصب‌کننده. |

## اجرای دوباره

اجرای همین دستور روی سروری که اویرا دارد، منوی `ovira` را باز می‌کند و از آنجا می‌توانید به‌روزرسانی کنید. اگر اویرا حذف شده ولی داده‌اش روی سرور مانده، نصب‌کننده سه انتخاب می‌دهد: نصب دوباره با نگه داشتن داده، نصب تازه (نسخهٔ پشتیبان داده‌های قدیمی در `/root` ذخیره می‌شود) یا انصراف.

## منوی `ovira`

روی سرور `ovira` را بزنید تا منو باز شود: وضعیت و آدرس، تغییر رمز یک مدیر، لایسنس و شناسهٔ دستگاه، گواهی HTTPS، راه‌اندازی مجدد، اجرا و توقف، لاگ زنده، این سرور به‌عنوان نود، نصب OpenConnect، به‌روزرسانی، پشتیبان‌گیری از پایگاه داده و حذف. هر گزینه دستور جداگانه هم دارد، مثل `ovira status` یا `ovira update`. [مرجع خط فرمان](/fa/reference/cli) را ببینید.
