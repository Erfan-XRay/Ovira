# HTTPS برای پنل

اویرا برای پنل از Let's Encrypt گواهی رایگان می‌گیرد و خودش تمدیدش می‌کند. روش را هنگام نصب یا بعداً در **تنظیمات ← دسترسی پنل**، در بلوک **HTTPS** بالای صفحه، انتخاب می‌کنید. این صفحه سه روش، چیزی که Let's Encrypt از سرور لازم دارد، و استفاده از گواهی خودتان را توضیح می‌دهد.

## انتخاب روش

| روش | کی استفاده شود |
|---|---|
| **دامنه** | دامنه دارید و رکورد A آن به این سرور اشاره می‌کند. بهترین گزینه است. |
| **آی‌پی سرور** | دامنه ندارید. گواهی برای آی‌پی سرور صادر می‌شود، فقط چند روز اعتبار دارد و خودکار تمدید می‌شود. |
| **بدون SSL** | HTTP ساده. رمزها بدون رمزنگاری در شبکه جابه‌جا می‌شوند؛ فقط پشت پراکسی TLS خودتان استفاده کنید. |

این بلوک وضعیت فعلی را نشان می‌دهد: گواهی برای چه نامی است، چه کسی صادر کرده و تا کی معتبر است. اگر آخرین تمدید ناموفق بوده باشد، دلیلش زیر خط وضعیت می‌آید.

## گرفتن گواهی

1. **تنظیمات ← دسترسی پنل** را باز کنید.
2. **دامنه** یا **آی‌پی سرور** را انتخاب کنید.
3. برای **دامنه**، نام دامنه را در فیلد **دامنه** بنویسید.
4. در صورت تمایل **ایمیل (اختیاری)** را وارد کنید. Let's Encrypt فقط وقتی گواهی نیاز به رسیدگی داشته باشد به آن پیام می‌دهد.
5. **دریافت گواهی** را بزنید.
6. **راه‌اندازی مجدد پنل** را بزنید. پنل با راه‌اندازی مجدد به HTTPS می‌رود و آدرس از `http://` به `https://` تغییر می‌کند.

برای برگشت به HTTP ساده، **بدون SSL** را انتخاب کنید، **استفاده از HTTP ساده** را بزنید و پنل را دوباره راه‌اندازی کنید.

## Let's Encrypt چه لازم دارد

Let's Encrypt با اتصال به سرور حدود یک دقیقه بررسی می‌کند که سرور مال شماست. اول پورت ۸۰ را امتحان می‌کند و اگر اشغال باشد پورت ۴۴۳ را. اگر برنامهٔ دیگری مثل nginx یا Caddy هر دو پورت را در زمان صدور نگه دارد، اویرا نمی‌تواند گواهی بگیرد. برای بررسی یکی از پورت‌ها را آزاد کنید، یا فایل‌های گواهی خودتان را به کار ببرید.

تمدید هم همین پورت را لازم دارد. گواهی‌ای که تمدید نشود منقضی می‌شود و مرورگرها دربارهٔ پنل هشدار می‌دهند. پنل گواهی تمدیدشده را بدون راه‌اندازی مجدد برمی‌دارد.

## استفاده از گواهی خودتان

در **تنظیمات ← دسترسی پنل**، **فایل گواهی TLS** و **فایل کلید TLS** را با مسیر کامل روی سرور پر کنید؛ مثلاً فایل‌هایی که `certbot` زیر `/etc/letsencrypt/live/` نگه می‌دارد. ذخیره و پنل را راه‌اندازی مجدد کنید. اگر هر دو را خالی بگذارید، گواهی مدیریت‌شدهٔ اویرا یا HTTP ساده به کار می‌رود.

## از خط فرمان

```bash
ovira ssl                  # منو: دامنه، آی‌پی یا خاموش
ovira ssl status           # گواهی و روش فعلی
ovira ssl off              # HTTP ساده؛ پنل را راه‌اندازی مجدد می‌کند
ovira ssl issue -mode domain -domain panel.example.com -email you@example.com
ovira ssl issue -mode ip   # گواهی برای آی‌پی سرور
systemctl restart ovira    # بعد از issue، تا پنل به HTTPS برود
```
