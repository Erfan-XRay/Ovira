# هاست‌ها

**هاست** یعنی هر سرور OpenVPN چگونه به کاربر نشان داده شود: نامی که می‌بیند، آدرس‌هایی که سرور روی آن‌ها جواب می‌دهد و تنظیمات سمت کاربر. ایده همان هاست‌های پاسارگارد است، با تنظیمات OpenVPN به‌جای Xray.

سروری که هاست ندارد با نام خودش و آدرس نودش نشان داده می‌شود. وقتی می‌خواهید اسم سرور را عوض کنید، سرور واسط جلویش بگذارید یا برای بعضی کاربران تنظیمات دیگری بدهید، هاست بسازید.

## ساخت هاست

**هاست‌ها ← ساخت هاست**:

| فیلد | کار |
|---|---|
| سرور | سرور OpenVPN که این هاست نشان می‌دهد. |
| نام | آنچه کاربر می‌بیند. خالی یعنی نام پیش‌فرض. می‌تواند متغیر داشته باشد (پایین‌تر). |
| آدرس‌ها | هر آدرس **یک پروفایل جدا** می‌شود. خالی یعنی آدرس خود سرور. |
| تنظیمات سمت کاربر | MSS fix، MTU تونل، مهلت اتصال، پروکسی HTTP یا SOCKS و دستورهای بیشتر OpenVPN. فقط به پروفایل‌های همین هاست اضافه می‌شود. |
| چه کسی می‌بیند | فقط کاربرانی با وضعیت‌های انتخابی و فقط کاربرانی در گروه‌های انتخابی. هر دو را خالی بگذارید تا برای همهٔ کاربرانی که سرور را دارند نشان داده شود. |
| نمایش در اشتراک | خاموش کنید تا هاست بدون حذف مخفی شود. |

هاست‌ها را بکشید تا ترتیبشان عوض شود؛ اشتراک‌ها به همین ترتیب فهرست می‌شوند. چند هاست را انتخاب کنید تا با هم فعال، غیرفعال یا حذف شوند.

## آدرس، سرور واسط و تونل

هر سرور واسط یا تونلی را که جلوی یک سرور گذاشته‌اید یک آدرس کنید:

| فیلد | مثال |
|---|---|
| برچسب | `واسط تهران` |
| آدرس | `ir1.example.com` (خالی = آدرس خود سرور) |
| پورت | خالی = پورت خود سرور، یا پورت واسط |

چهار واسط جلوی یک سرور یعنی چهار پروفایل برای انتخاب، و یک خط `remote` جایگزین در پروفایل «همه در یک فایل». پروفایل‌های هاست‌هایی که تنظیمات سمت کاربرشان فرق دارد هیچ‌وقت در یک فایل ادغام نمی‌شوند.

## متغیرهای نام

نام برای هر کاربر پر می‌شود. در ویرایشگر روی یک متغیر بزنید تا اضافه شود؛ پیش‌نمایش نتیجه را نشان می‌دهد.

| متغیر | چه نشان می‌دهد |
|---|---|
| `{USERNAME}` | نام کاربر |
| `{SERVER}` / `{NODE}` | سرور OpenVPN و نودش |
| `{LABEL}` / `{ADDRESS}` | برچسب و آدرس |
| `{PROTOCOL}` / `{PORT}` | UDP یا TCP و پورت |
| `{DATA_USAGE}` / `{DATA_LIMIT}` / `{DATA_LEFT}` | مصرف‌شده، مجاز و باقی‌مانده |
| `{USAGE_PERCENTAGE}` | درصد مصرف |
| `{DAYS_LEFT}` / `{TIME_LEFT}` | زمان تا پایان |
| `{EXPIRE_DATE}` / `{JALALI_EXPIRE_DATE}` | تاریخ پایان، میلادی و شمسی |
| `{STATUS_EMOJI}` | ایموجی وضعیت کاربر |

حجم یا زمان نامحدود به‌صورت `∞` و تاریخ نبود به‌صورت `-` نشان داده می‌شود. نامی مثل `🇩🇪 {SERVER} · {DATA_LEFT} · {DAYS_LEFT}d` در صفحهٔ اشتراک نام پروفایل می‌شود و کاربر بدون باز کردن صفحه می‌بیند چه مانده.

## هاست‌هایی که گاهی دیده می‌شوند

- **وضعیت کاربر**: هاست فقط برای کاربران فعال، تمام‌شده، منقضی یا غیرفعال نشان داده می‌شود. هاستی برای کاربران منقضی می‌تواند در نامش یادآور تمدید داشته باشد.
- **گروه‌ها**: هاست فقط برای کاربران آن گروه‌ها نشان داده می‌شود؛ پس یک سرور را می‌شود برای مشتری‌های مختلف جور دیگری عرضه کرد.

::: tip
هر کاربر فقط هاست‌هایی را می‌بیند که اجازه دارد. اگر همهٔ هاست‌های یک سرور برای کاربری پنهان باشند، آن سرور برایش نمی‌آید. آخرین هاست یک سرور را حذف کنید تا به آدرس نودش برگردد.
:::

## از آدرس‌های اتصال قبلی

نسخه‌های قبل از ۰٫۴ آدرس سرورهای واسط را روی نود نگه می‌داشتند. هنگام به‌روزرسانی آن‌ها به هاست تبدیل شدند، برای هر سرور یکی، و فهرست نود خالی شد. برای کاربران چیزی عوض نمی‌شود.
