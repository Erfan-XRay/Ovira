# رفع مشکل

### کدام پروتکل‌های VPN در دسترس‌اند؟

اویرا از **OpenVPN** و **OpenConnect** (Cisco Secure Client / AnyConnect) پشتیبانی می‌کند. هر کلاینت با همان نام و گذرواژه روی هر دو کار می‌کند؛ پروفایل OpenVPN در برنامه‌های سیسکو کار نمی‌کند و برای آن‌ها باید سرور OpenConnect را به کار ببرید. بخش [OpenConnect (سیسکو)](./openconnect) را ببینید.

### آیا اویرا پشتیبانی تلگرام دارد؟

این پروژه سرویس رسمی پشتیبانی تلگرام ندارد. لینک پشتیبانی که مالک پنل تنظیم می‌کند متعلق به همان مالک است، نه اویرا. برای اطلاعات پروژه از این راهنما و [مخزن پروژه](https://github.com/Erfan-XRay/Ovira) استفاده کنید.

### برنامهٔ سیسکو «سرور نامعتبر» می‌گوید (OpenConnect)

گزینهٔ **Block untrusted servers** را در تنظیمات Cisco Secure Client خاموش کنید، یا برای آن سرور از گواهی پنل استفاده کنید. بخش [OpenConnect (سیسکو)](./openconnect#گواهی) را ببینید.

### آدرس پنل را گم کرده‌ام

```bash
ovira info
```

### رمز را فراموش کرده‌ام یا برنامهٔ احراز هویت را از دست داده‌ام

```bash
ovira admin passwd -username admin
ovira admin reset-2fa -username admin
```

### کاربر وصل می‌شود ولی اینترنت ندارد

- **NAT** را برای آن سرور بررسی کنید (**سرورها ← سرور ← شبکه**).
- فایروال دیگری (مثلاً فایروال دیتاسنتر) باید پورت OpenVPN را باز گذاشته باشد.
- روی سرورهایی که فایروالشان nftables است، اویرا قوانینش را در جدول جداگانهٔ `ovira` نگه می‌دارد: `nft list table ip ovira`.

### «device limit reached»

کاربر به اندازهٔ مجاز اتصال باز دارد (روی همهٔ سرورها و نودها با هم). یک اتصال قدیمی را از **اتصال‌ها** قطع کنید یا محدودیت را بالا ببرید.

### دو دستگاه با یک پروفایل همدیگر را قطع می‌کنند

به آخرین نسخه به‌روزرسانی کنید: اویرا اجازه می‌دهد یک پروفایل روی چند دستگاه کار کند و محدودیت دستگاه را خودش اعمال می‌کند.

### نود «در دسترس نیست» نشان می‌دهد

- پورت نود (پیش‌فرض 62060) باید از سرور پنل در دسترس باشد.
- اگر نود با `--panel-ip` نصب شده، پنل باید از همان آی‌پی وصل شود.
- بعد از نصب دوبارهٔ نود، کلید جدیدش را وارد کنید (`ovira key` روی نود).

### پورت 62060 روی نود اشغال است

ممکن است نود پنل دیگری از آن استفاده کند. با پورت دیگر نصب کنید: `node --port 62070` و همان پورت را در پنل وارد کنید.

### گواهی HTTPS گرفته نمی‌شود

خطای پنل یا نصب‌کننده را ببینید. اشغال‌بودن هر دو پورت اعتبارسنجی، بسته‌بودن پورت ورودی، اشارهٔ دامنه به سرور دیگر یا محدودیت مرجع گواهی از علت‌های رایج‌اند. [HTTPS](./https) را ببینید.

### پنل می‌گوید سرور لایسنس در دسترس نیست

پنل برای تمدید لایسنس به HTTPS خروجی به `ovpn.rapcity.shop` نیاز دارد.
