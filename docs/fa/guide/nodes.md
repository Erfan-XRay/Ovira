# نودها و سرورهای واسط

**نود** سرور دیگری است که برای پنل شما OpenVPN اجرا می‌کند. کاربر یک بار در پنل ساخته می‌شود و روی همهٔ نودها کار می‌کند.

## افزودن نود

**۱. روی سرور جدید** با root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/Ovira/main/install.sh) --node --panel-ip PANEL_IP
```

`--panel-ip` باعث می‌شود نود فقط به پنل شما جواب بدهد. نصب‌کننده یک **کلید نود** (`BNK1-…`) چاپ می‌کند. نود روی پورت TCP **62060** گوش می‌دهد؛ برای پورت دیگر از `--port` استفاده کنید.

**۲. در پنل**، **نودها ← اتصال نود**، کلید را وارد کنید، اسم بدهید و ذخیره کنید. پنل در چند ثانیه وصل می‌شود.

**۳. یک سرور OpenVPN روی آن بسازید**: در کارت نود، **افزودن سرور اینجا**. پورت و پروتکل را مثل سرور اصلی انتخاب کنید.

کلید نود شامل کلید API و اثر انگشت گواهی نود است، پس پنل فقط با همان نود حرف می‌زند. اگر نود را دوباره نصب کردید، کلید جدیدش را در ویرایش نود وارد کنید. `ovira node key` کلید را دوباره چاپ می‌کند.

## دستگاه هم‌زمان

محدودیت دستگاه اتصال‌های کاربر را روی **همهٔ** سرورها با هم می‌شمارد. با محدودیت ۲، کاربر هر جا می‌تواند دو دستگاه داشته باشد: هر دو روی یک نود یا هر کدام روی یکی.

## ضریب مصرف

هر نود (و سرور اصلی) یک ضریب برای حساب حجم دارد:

| ضریب | یک گیگ مصرف آن‌جا حساب می‌شود |
|---|---|
| ×۱ | ۱ گیگ |
| ×۱٫۵ | ۱٫۵ گیگ |
| ×۰٫۵ | ۰٫۵ گیگ |
| ×۰ | هیچ (ترافیک رایگان) |

ترافیکی که در کارت نود نشان داده می‌شود همیشه مقدار واقعی است. صفحهٔ اشتراک ضریب را کنار هر سرور نشان می‌دهد.

## سرور واسط و تونل

برای گذاشتن **سرور واسط** جلوی یک نود (مثلاً سرورهای داخل کشور که به نودی در خارج تونل شده‌اند)، برای سرور OpenVPN آن نود یک **هاست** با آدرس واسط‌ها بسازید: [هاست‌ها](/fa/guide/hosts). هر آدرس در صفحهٔ اشتراک یک پروفایل جدا می‌شود.

## وقتی نود قطع می‌شود

اتصال‌های روی آن باز می‌مانند. وقتی نود برگشت، پنل دوباره وصل می‌شود، تغییرات این مدت را می‌فرستد و ترافیک را بدون دوبار شمردن حساب می‌کند.

## حذف نود

**نودها ← ⋯ ← حذف نود** سرورهای OpenVPN آن را متوقف و از همهٔ پروفایل‌ها حذف می‌کند. برای پاک کردن نرم‌افزار از خود نود:

```bash
bash install.sh --node --uninstall --purge
```
