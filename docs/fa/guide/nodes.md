# نودها و سرورهای واسط

**نود** سرور دیگری است که برای پنل شما اینباندهای OpenVPN، OpenConnect یا WireGuard اجرا می‌کند. کاربر یک بار در پنل ساخته می‌شود و روی همهٔ نودها کار می‌کند.

## افزودن نود

**۱. در پنل**، **نودها ← اتصال نود** را باز کنید. دستور نصب را با آدرس پنل شما پر شده نشان می‌دهد؛ دکمهٔ کپی را بزنید و با root روی سرور جدید اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/Ovira/main/node.sh) --panel-ip PANEL_IP
```

اسکریپت اویرا را خودش از گیت‌هاب می‌گیرد، پس لازم نیست چیزی از قبل روی سرور جدید کپی کنید. `--panel-ip` باعث می‌شود نود فقط به پنل شما جواب بدهد. در پایان یک **کلید نود** (`BNK1-…`) چاپ می‌کند. نود روی پورت TCP **62060** گوش می‌دهد؛ برای پورت دیگر از `--port` استفاده کنید.

**۲. برگردید به همان پنجره**، کلید را وارد کنید، به نود اسم بدهید و ذخیره کنید. پنل در چند ثانیه وصل می‌شود.

**۳. یک اینباند متصل کنید**: اول در **اینباندها ← اینباند جدید** آن را بسازید، بعد روی کارت نود **اتصال اینباند** را بزنید و آن را از **بدون نود** انتخاب کنید. همهٔ کارت‌ها، از جمله **همین سرور**، این دکمه را دارند. نود مقصد پیش از اجرای اینباند بررسی می‌شود؛ اگر بررسی ناموفق باشد، چیزی تغییر نمی‌کند و دلیل در پنجره نشان داده می‌شود. برای **OpenConnect** روی **همین سرور**، پیش از اتصال، **نصب OpenConnect** را روی همان کارت بزنید.

آیکون **جدا کردن** کنار اینباند آن را متوقف می‌کند و به **بدون نود** برمی‌گرداند؛ دسترسی کاربران حفظ می‌شود، ولی کاربران متصل قطع می‌شوند. برای جابه‌جایی، با **اتصال اینباند** در کارت نود دیگری آن را انتخاب کنید؛ نود جدید پیش از جدا شدن اینباند از نود قبلی بررسی می‌شود.

کلید نود شامل کلید API و اثر انگشت گواهی نود است، پس پنل فقط با همان نود حرف می‌زند. اگر نود را دوباره نصب کردید، کلید جدیدش را در ویرایش نود وارد کنید. `ovira key` روی نود کلید را دوباره چاپ می‌کند.

## سرور خود پنل

پنل را می‌شود **تنها** نصب کرد (پنل خالی که فقط نودها را مدیریت می‌کند) یا با OpenVPN روی همان سرور؛ [نصب](./install#پنل-با-openvpn-یا-پنل-خالی) را ببینید. روی پنل خالی کارت سرور اصلی «فقط پنل» می‌نویسد. برای اینکه آن سرور هم نود شود، روی آن بزنید:

```bash
ovira openvpn enable
```

اگر لازم باشد OpenVPN را نصب می‌کند و اولین اینباندها را می‌سازد. `ovira openvpn disable` دوباره متوقفشان می‌کند؛ پنل و نودهای دیگر به کارشان ادامه می‌دهند.

## دستگاه هم‌زمان

محدودیت دستگاه اتصال‌های کاربر را روی **همهٔ** اینباندها با هم می‌شمارد. با محدودیت ۲، کاربر هر جا می‌تواند دو دستگاه داشته باشد: هر دو روی یک نود یا هر کدام روی یکی.

## ضریب مصرف

هر نود (و سرور اصلی) یک ضریب برای حساب حجم دارد:

| ضریب | یک گیگ مصرف آن‌جا حساب می‌شود |
|---|---|
| ×۱ | ۱ گیگ |
| ×۱٫۵ | ۱٫۵ گیگ |
| ×۰٫۵ | ۰٫۵ گیگ |
| ×۰ | هیچ (ترافیک رایگان) |

ترافیکی که در کارت نود نشان داده می‌شود همیشه مقدار واقعی است. صفحهٔ اشتراک ضریب را کنار هر اینباند نشان می‌دهد.

## آدرس‌های اتصال (سرور واسط و تونل)

به‌طور پیش‌فرض کاربران به آدرس خود نود وصل می‌شوند. اگر **سرور واسط** جلوی نود دارید (مثلاً سرورهای داخل کشور که به نود خارج تونل شده‌اند)، آدرس‌هایشان را در ویرایش نود در بخش **آدرس‌های اتصال** اضافه کنید:

| فیلد | مثال |
|---|---|
| برچسب | `واسط تهران` |
| آدرس | `ir1.example.com` |
| پورت | خالی یعنی پورت خود سرور، یا پورت سرور واسط |
| برای | همهٔ اینباندها یا یک اینباند OpenVPN خاص روی نود |

هر آدرس فعال در صفحهٔ اشتراک یک پروفایل اتصال می‌سازد. پروفایل «همه در یک فایل» فقط اینباندهای سازگار با تنظیمات OpenVPN اولین اینباند را به‌صورت `remote` جایگزین می‌آورد؛ همهٔ پروتکل‌ها و حالت‌های ورود را در یک فایل ترکیب نمی‌کند. خود سرور واسط یا تونل را باید جداگانه راه‌اندازی کنید؛ افزودن آدرس اتصال فقط آدرس‌هایی را که به کاربر نمایش داده می‌شود عوض می‌کند.

::: warning توجه
وقتی نود آدرس اتصال دارد، پروفایل‌ها فقط از همین آدرس‌ها استفاده می‌کنند. اگر کاربران مستقیم هم وصل می‌شوند، آدرس خود نود را هم اضافه کنید.
:::

## وقتی نود قطع می‌شود

اگر فقط ارتباط مدیریتی قطع شود، پردازش‌های OpenVPN ممکن است اتصال‌های قبلی را باز نگه دارند؛ احراز هویت جدید و اعمال زندهٔ سهمیه به ارتباط پنل وابسته‌اند. خاموشی سرور یا سرویس VPN اتصال‌ها را قطع می‌کند. پس از اتصال دوباره، پنل نشست‌های باقی‌مانده و شمارنده‌هایشان را تطبیق می‌دهد؛ شمارنده‌هایی که با ری‌استارت خود پردازش VPN از دست رفته‌اند قابل بازیابی نیستند.

## حذف نود

**نودها ← ⋯ ← حذف نود** اینباندهای آن را متوقف می‌کند و با حفظ دسترسی کاربران به **بدون نود** می‌برد. برای اجرای دوباره، آن‌ها را به نود دیگری متصل کنید. برای پاک کردن نرم‌افزار از خود نود:

```bash
ovira --node --uninstall --purge
```
