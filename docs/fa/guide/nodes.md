# نودها و سرورهای واسط

**نود** سرور دیگری است که برای پنل شما سرورهای OpenVPN یا OpenConnect اجرا می‌کند. کاربر یک بار در پنل ساخته می‌شود و روی همهٔ نودها کار می‌کند.

## افزودن نود

**۱. در پنل**، **نودها ← اتصال نود** را باز کنید. دستور نصب را با آدرس پنل شما پر شده نشان می‌دهد؛ دکمهٔ کپی را بزنید و با root روی سرور جدید اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erfan-XRay/Ovira/main/install.sh) node --panel-ip PANEL_IP
```

اسکریپت اویرا را خودش از گیت‌هاب می‌گیرد، پس لازم نیست چیزی از قبل روی سرور جدید کپی کنید. `--panel-ip` باعث می‌شود نود فقط به پنل شما جواب بدهد. در پایان یک **کلید نود** (`BNK1-…`) چاپ می‌کند. نود روی پورت TCP **62060** گوش می‌دهد؛ برای پورت دیگر از `--port` استفاده کنید.

**۲. برگردید به همان پنجره**، کلید را وارد کنید، به نود اسم بدهید و ذخیره کنید. پنل در چند ثانیه وصل می‌شود.

**۳. یک سرور روی آن بسازید**: در کارت نود، **افزودن سرور اینجا**. مثل سرور اصلی OpenVPN یا OpenConnect و بعد پورت را انتخاب کنید. اولین سرور OpenConnect، OpenConnect را خودکار روی نود نصب می‌کند و تا آن موقع کارت نود *OpenConnect نصب نیست* را نشان می‌دهد. نودی که نسخهٔ قدیمی اویرا دارد *برای OpenConnect این نود را به‌روز کنید* را نشان می‌دهد؛ اول آن را به‌روز کنید.

کلید نود شامل کلید API و اثر انگشت گواهی نود است، پس پنل فقط با همان نود حرف می‌زند. اگر نود را دوباره نصب کردید، کلید جدیدش را در ویرایش نود وارد کنید. `ovira key` روی نود کلید را دوباره چاپ می‌کند.

## سرور خود پنل

پنل را می‌شود **تنها** نصب کرد (پنل خالی که فقط نودها را مدیریت می‌کند) یا با OpenVPN روی همان سرور؛ [نصب](./install#پنل-با-openvpn-یا-پنل-خالی) را ببینید. روی پنل خالی کارت سرور اصلی «فقط پنل» می‌نویسد. برای اینکه آن سرور هم نود شود، روی آن بزنید:

```bash
ovira openvpn enable
```

اگر لازم باشد OpenVPN را نصب می‌کند و اولین سرورها را می‌سازد. `ovira openvpn disable` دوباره متوقفشان می‌کند؛ پنل و نودهای دیگر به کارشان ادامه می‌دهند.

## دستگاه هم‌زمان

محدودیت دستگاه اتصال‌های کاربر را روی **همهٔ** سرورها با هم می‌شمارد. با محدودیت ۲، کاربر هر جا می‌تواند دو دستگاه داشته باشد: هر دو روی یک نود یا هر کدام روی یکی.

## ضریب مصرف

هر نود (و سرور اصلی) یک ضریب برای حساب حجم دارد:

| ضریب | یک گیگ مصرف آن‌جا حساب می‌شود |
|---|---|
| ×۱ | ۱ گیگ |
| ×۱٫۵ | ۱٫۵ گیگ |
| ×۰٫۵ | ۰٫۵ گیگ |
| ×۰ | هیچ (ترافیک رایگان) |

ترافیکی که در کارت نود نشان داده می‌شود همیشه مقدار واقعی است. صفحهٔ اشتراک ضریب را کنار هر سرور نشان می‌دهد.

## آدرس‌های اتصال (سرور واسط و تونل)

به‌طور پیش‌فرض کاربران به آدرس خود نود وصل می‌شوند. اگر **سرور واسط** جلوی نود دارید (مثلاً سرورهای داخل کشور که به نود خارج تونل شده‌اند)، آدرس‌هایشان را در ویرایش نود در بخش **آدرس‌های اتصال** اضافه کنید:

| فیلد | مثال |
|---|---|
| برچسب | `واسط تهران` |
| آدرس | `ir1.example.com` |
| پورت | خالی یعنی پورت خود سرور، یا پورت سرور واسط |
| برای | همهٔ سرورها یا یک سرور OpenVPN خاص روی نود |

هر آدرس در صفحهٔ اشتراک **یک پروفایل جدا** می‌شود و در پروفایل «همه در یک فایل» هم یک خط `remote` جایگزین می‌گیرد. چهار سرور واسط جلوی دو نود یعنی کاربر چهار پروفایل برای انتخاب دارد.

::: warning توجه
وقتی نود آدرس اتصال دارد، پروفایل‌ها فقط از همین آدرس‌ها استفاده می‌کنند. اگر کاربران مستقیم هم وصل می‌شوند، آدرس خود نود را هم اضافه کنید.
:::

## وقتی نود قطع می‌شود

اتصال‌های روی آن باز می‌مانند. وقتی نود برگشت، پنل دوباره وصل می‌شود، تغییرات این مدت را می‌فرستد و ترافیک را بدون دوبار شمردن حساب می‌کند.

## حذف نود

**نودها ← ⋯ ← حذف نود** سرورهای OpenVPN آن را متوقف و از همهٔ پروفایل‌ها حذف می‌کند. برای پاک کردن نرم‌افزار از خود نود:

```bash
bash install.sh --node --uninstall --purge
```
