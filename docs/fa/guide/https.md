# HTTPS

اویرا از Let's Encrypt گواهی رایگان می‌گیرد و خودش تمدیدش می‌کند. حالت را موقع نصب یا بعداً در **تنظیمات ← دسترسی پنل ← HTTPS** انتخاب کنید.

| حالت | چه وقت | عمر گواهی |
|---|---|---|
| **دامنه** | دامنه‌ای دارید که رکورد A آن به سرور اشاره می‌کند | ۹۰ روز، تمدید ۳۰ روز مانده به پایان |
| **آی‌پی سرور** | دامنه ندارید | حدود ۶ روز، تمدید هر ۲ روز |
| **بدون SSL** | پشت پراکسی TLS خودتان، یا برای تست | — |

## چطور کار می‌کند

Let's Encrypt حدود یک دقیقه به سرور وصل می‌شود تا مطمئن شود سرور مال شماست:

- روی **پورت ۸۰** (HTTP-01)، یا
- روی **پورت ۴۴۳** (TLS-ALPN-01) اگر ۸۰ اشغال باشد.

اگر برنامهٔ دیگری (nginx، Caddy، Xray…) **هر دو** پورت را گرفته باشد، اویرا نمی‌تواند گواهی بگیرد. موقع صدور و تمدید یکی از آن‌ها را آزاد کنید، یا فایل گواهی خودتان را در **تنظیمات ← دسترسی پنل ← فایل گواهی / فایل کلید** بدهید.

بعد از گرفتن گواهی، **ری‌استارت** را بزنید تا پنل به HTTPS برود. تمدیدها بدون ری‌استارت اعمال می‌شوند.

## از خط فرمان

```bash
ovira ssl issue -mode domain -domain panel.example.com -email you@example.com
ovira ssl issue -mode ip            # آی‌پی عمومی سرور را خودش پیدا می‌کند
ovira ssl status
ovira ssl off                       # برگشت به HTTP ساده
systemctl restart ovira
```
