# تنظیمات

**تنظیمات** گزینه‌های سراسری پنل را دارد. به‌صورت زبانه‌هایی سازمان یافته و زبانه‌هایی که می‌بینید به نقش شما بستگی دارد. این صفحه همهٔ زبانه‌ها و، برای زبانهٔ **عمومی**، همهٔ فیلدها را فهرست می‌کند. زبانه‌هایی که صفحهٔ جدا دارند لینک شده‌اند.

## زبانه‌ها

| زبانه | چه کسی می‌بیند | چه چیزی دارد |
|---|---|---|
| **عمومی** | مالک‌ها | آدرس‌ها، زبان، رنگ، آستانه‌های هشدار، مدت نگهداری تاریخچه، نسخه. |
| **صفحهٔ اشتراک** | مالک‌ها | ظاهر صفحهٔ کاربران. [صفحهٔ اشتراک](/fa/use/subscription-page) را ببینید. |
| **دسترسی پنل** | مالک‌ها | آدرس خود پنل، مسیر مخفی و HTTPS. |
| **حساب من** | همه | رمز، ورود دومرحله‌ای و دستگاه‌های وارد شدهٔ شما. [حساب‌های پنل](/fa/use/admins) را ببینید. |
| **پشتیبان** | مالک‌ها | دانلود و بازگردانی. [پشتیبان‌گیری و بازگردانی](/fa/use/backup) را ببینید. |
| **گزارش فعالیت** | مالک‌ها و نقش‌هایی که همهٔ کاربران را می‌بینند | چه کسی چه کرده. [گزارش فعالیت](/fa/use/audit) را ببینید. |

## عمومی

| فیلد | چه کار می‌کند |
|---|---|
| **آدرس عمومی** | دامنه یا آی‌پی‌ای که پروفایل کاربران به آن وصل می‌شود. نصب‌کننده آن را پر می‌کند. هر اینباند می‌تواند با **آدرس عمومی جایگزین** آن را عوض کند. |
| **آدرس لینک اشتراک** | اختیاری، مثلاً `https://sub.example.com`. خالی یعنی آدرسی که پنل را با آن باز کرده‌اید. |
| **زبان پیش‌فرض صفحه کاربران** | انگلیسی یا فارسی. |
| **رنگ پنل** | رنگ تأکید پنل برای همهٔ کسانی که وارد می‌شوند: **لیمویی**، **فیروزه‌ای**، **نعنایی**، **کهربایی**، **مرجانی**، **گلی**، **بنفش** یا **آسمانی**. با انتخاب پیش‌نمایش می‌شود و با **ذخیره** ثبت می‌شود. صفحهٔ کاربران رنگ خودش را دارد. |
| **هشدار وقتی پلن تا این مدت تمام می‌شود** | روز. کاربرانی که از این فاصله به تاریخ پایانشان نزدیک‌ترند زیر **رو به اتمام** می‌آیند. |
| **هشدار وقتی مصرف به این درصد برسد** | درصد. کاربرانی که از آن بیشتر مصرف کرده‌اند زیر **رو به اتمام** می‌آیند. |
| **خروج خودکار پس از بی‌فعالیتی** | ساعت. بعد از این مدت بدون فعالیت، مرورگر وارد شده خارج می‌شود. |
| **نمودار ترافیک** | چند روز تاریخچهٔ مصرف نگه داشته شود. |
| **گزارش اتصال‌ها** | چند روز اتصال‌های تمام‌شده نگه داشته شود. |
| **گزارش فعالیت** | چند روز گزارش فعالیت نگه داشته شود. |

بخش پایین نسخهٔ نصب‌شدهٔ اویرا و OpenVPN، سیستم‌عامل و **شناسه دستگاه** این سرور را با دکمهٔ کپی نشان می‌دهد. وقتی خارج از پنل لایسنس می‌خرید یا تمدید می‌کنید، آن را می‌دهید.

## دسترسی پنل

بلوک بالا **HTTPS** است و در [HTTPS برای پنل](/fa/start/https) توضیح داده شده. زیر آن فیلدهایی است که تعیین می‌کنند پنل کجا پاسخ بدهد.

| فیلد | چه کار می‌کند |
|---|---|
| **آدرس شنود** | پورتی که پنل روی آن گوش می‌دهد، مثلاً `:2053`. پشت پراکسی معکوس `127.0.0.1:2053` بگذارید. |
| **مسیر مخفی** | پنل فقط زیر این مسیر پاسخ می‌دهد. بقیهٔ آدرس‌ها شبیه سرور خالی است. |
| **مسیر اشتراک** | بخش اول لینک‌های اشتراک. |
| **فایل گواهی TLS**، **فایل کلید TLS** | گواهی خودتان به‌صورت مسیر کامل روی سرور. برای HTTP ساده یا گواهی مدیریت‌شدهٔ اویرا خالی بگذارید. |
| **پشت پراکسی معکوس (اعتماد به X-Forwarded-For)** | فقط وقتی روشن کنید که پراکسیِ خودتان آن هدر را می‌گذارد. |

این‌ها بعد از راه‌اندازی مجدد اعمال می‌شوند. **ذخیره** آن‌ها را نگه می‌دارد، صفحه می‌گوید «ذخیره شد. برای اعمال، پنل را دوباره راه‌اندازی کنید.»، و **راه‌اندازی مجدد پنل** اعمالشان می‌کند. صفحه آدرس جدید را به شکل «پس از راه‌اندازی، پنل در ... خواهد بود» نشان می‌دهد. پیش از راه‌اندازی مجدد آن را یادداشت کنید. اتصال‌های VPN از راه‌اندازی مجدد تأثیر نمی‌گیرند.

::: warning
**آدرس شنود** یا **مسیر مخفی** غلط، بعد از راه‌اندازی مجدد پنل را در دسترس‌ناپذیر می‌کند. پیش از راه‌اندازی آدرس زیر فیلدها را بررسی کنید. اگر از پنل بیرون ماندید، `ovira status` روی سرور آدرسی را که پنل حالا دارد چاپ می‌کند.
:::
