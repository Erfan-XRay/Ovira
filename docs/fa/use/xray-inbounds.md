# اینباندهای Xray

اینباند Xray به کاربرانی سرویس می‌دهد که از برنامه‌های پروکسی مثل Happ، v2rayNG و Hiddify استفاده می‌کنند. کنار اینباندهای OpenVPN، WireGuard و OpenConnect قرار می‌گیرد: همان کاربران، گروه‌ها، سهمیه‌ها و لینک‌های اشتراک.

## یک سناریو انتخاب کنید

**اینباند جدید** را بزنید و **Xray** را انتخاب کنید. هر سناریو بقیهٔ موارد را خودش پر می‌کند.

| سناریو | کی استفاده کنید |
|---|---|
| **اتصال مستقیم** (پیشنهادی) | کاربران مستقیم به نود وصل می‌شوند. چیزی لازم نیست وارد کنید. |
| **پشت CDN (کلودفلر)** | کاربران از راه دامنه‌ای روی کلودفلر به نود می‌رسند. |
| **پشت سرور ایران (relay / تانل)** | کاربران از راه یک رله، مثلاً سروری در ایران، به نود می‌رسند. |
| **VMess کلاسیک** | برای برنامه‌های قدیمی‌تر VMess لازم دارید. |
| **Trojan** | Trojan لازم دارید. |
| **Shadowsocks** | Shadowsocks لازم دارید. |
| **دستی (پیشرفته)** | می‌خواهید همهٔ تنظیم‌ها را خودتان انتخاب کنید. |

## ساخت

۱. سناریو را انتخاب کنید.
۲. اگر چیزی خواست، پر کنید.
۳. **ساخت** را بزنید و اینباند را مثل بقیهٔ اینباندها به یک نود وصل کنید.

پورت و بقیهٔ تنظیم‌ها خودکار انتخاب می‌شوند و بعداً قابل تغییرند.

- **مستقیم** چیز دیگری نمی‌خواهد.
- **CDN** دامنه‌ای روی کلودفلر می‌خواهد که به نود اشاره کند.
- **رله** آی‌پی سرورهای رله را می‌خواهد. بعد از تنظیم، فقط رله‌ها می‌توانند وصل شوند و اتصال مستقیم کار نمی‌کند. پنل نمونه‌پیکربندی‌هایی برای سرورهای رله نشان می‌دهد.

## کاربران

کاربران روی اینباند Xray همان محدودیت سرعت و دستگاه بقیهٔ اینباندها را دارند. صفحهٔ کاربر لینک‌های Xray و برای هرکدام یک کد QR نشان می‌دهد، و می‌توانید لینک‌های کاربر را از همان صفحه عوض کنید.

موتور Xray وقتی اینباند Xray را به یک نود وصل می‌کنید خودکار روی آن نصب می‌شود.
