# نودها

[نود](/fa/reference/glossary) سروری است که برای پنل اینباند اجرا می‌کند، با هر پروتکلی. صفحهٔ **نودها** برای هر نود یک کارت نشان می‌دهد، با شروع از **همین سرور**. کاربری که یک بار ساخته شود روی همهٔ نودها کار می‌کند و محدودیت دستگاهش روی همهٔ آن‌ها با هم شمرده می‌شود. این صفحه کارت‌ها، پنجرهٔ نود، ضریب مصرف، آدرس‌های اتصال برای سرورهای واسط و حذف نود را توضیح می‌دهد. برای نصب نود، [افزودن نود](/fa/start/add-node) را ببینید.

## کارت‌ها

هر کارت نام نود و وضعیتش را نشان می‌دهد:

| وضعیت | معنی |
|---|---|
| **متصل** | پنل به نود می‌رسد. |
| **در دسترس نیست** | پنل نمی‌تواند به آن برسد. کارت نشان می‌دهد آخرین بار کی دیده شد. |
| **غیرفعال** | نود را در پنجره‌اش خاموش کرده‌اید. |
| **فقط پنل** | کارت **همین سرور** وقتی سرور اینباند اجرا نمی‌کند. |

یک نشان ضریب مصرف را نشان می‌دهد. زیر نام:

- **آنلاین**، **اینباندها**، **ترافیک واقعی**، و برای نودی که گزارش می‌دهد **پردازنده**، **حافظه** و **روشن از**.
- نسخه‌ها: «اویرا X · OpenVPN Y»، بعد «وایرگارد آماده است» یا «TUN در دسترس نیست». WireGuard روی نود به `/dev/net/tun` نیاز دارد.
- وضعیت OpenConnect: نسخه‌اش، یا اینکه نصب نیست، یا «برای OpenConnect این نود را به‌روز کنید» برای نود قدیمی.
- **آدرس‌های اتصال**، اگر داشته باشد.
- اینباندهای روی نود، هر کدام با آیکون **جدا کردن**، و دکمهٔ **اتصال اینباند**.

مالک‌ها **ویرایش** و منوی **بیشتر** را هم می‌بینند:

| عمل | چه کار می‌کند |
|---|---|
| **ارسال دوبارهٔ تنظیمات** | پیکربندی نود را دوباره به آن می‌فرستد. برای **همین سرور** نیست. |
| **صفر کردن شمارندهٔ ترافیک** | شمارندهٔ ترافیک نود را صفر می‌کند. |
| **حذف نود** | نود را از پنل برمی‌دارد؛ پایین‌تر را ببینید. برای **همین سرور** نیست. |

وقتی به سقف برسید، بنر صفحه می‌گوید «لایسنس شما N نود را مجاز می‌داند». سرور خود پنل در این سقف نمی‌شمارد. وصل کردن نود لایسنسی با قابلیت نود می‌خواهد و پلن رایگان دو نود می‌دهد.

## متصل کردن، جدا کردن و جابه‌جا کردن اینباند

اینباندهای تازه زیر **بدون نود** ذخیره می‌شوند و اجرا نمی‌شوند. روی یک کارت **اتصال اینباند** را بزنید، اینباند را در **اینباند را انتخاب کنید** برگزینید و تأیید کنید. پنل اول نود را بررسی می‌کند: پورت، هم‌پوشانی شبکه‌های تونل، و برای OpenConnect نرم‌افزار و گواهی. اگر بررسی ناموفق باشد چیزی تغییر نمی‌کند و پنجره دلیل را می‌گوید.

**جدا کردن** اینباند را متوقف می‌کند و به **بدون نود** برمی‌گرداند. کاربران دسترسی‌شان را نگه می‌دارند و کاربرانِ متصل به آن قطع می‌شوند. برای جابه‌جایی، روی نود دیگر **اتصال اینباند** را بزنید و آن را از **انتقال از نود دیگر** انتخاب کنید. نود جدید پیش از رفتن اینباند از نود قبلی بررسی می‌شود و کاربران متصل قطع می‌شوند.

برای OpenConnect روی **همین سرور**، اول روی کارت **نصب OpenConnect** را بزنید. نودهای راه دور وقتی اینباند متصل می‌شود خودشان نصبش می‌کنند.

## پنجرهٔ نود

**اتصال نود** پنجره را در سه مرحله باز می‌کند؛ **ویرایش** همین فیلدها را برای نود موجود باز می‌کند.

| فیلد | چه کار می‌کند |
|---|---|
| **کلید نود** | کلیدی که نصب‌کنندهٔ نود چاپ کرد. هنگام ویرایش برای نگه داشتن کلید فعلی خالی بگذارید و بعد از نصب دوبارهٔ نود کلید جدید را بچسبانید. |
| **آدرس نود** | آی‌پی یا دامنه‌ای که پنل با آن به نود وصل می‌شود. از روی کلید پر می‌شود. |
| **پورت نود** | پورتی که نود روی آن گوش می‌دهد. پیش‌فرض `62060`. |
| **نام** | ۱ تا ۴۰ نویسه. در صفحهٔ اشتراک نمایش داده می‌شود. |
| **ضریب مصرف** | ترافیک نود چطور در سهمیه حساب شود، از ۰ تا ۲۰. |
| **آدرس‌های اتصال** | آدرس‌هایی که کاربران به‌جای آدرس خود نود به کار می‌برند. پایین‌تر را ببینید. |
| **یادداشت** | متن آزاد، تا ۵۰۰ نویسه. |
| **فعال** | اگر خاموش باشد، پنل نود را مدیریت نمی‌کند و اینباندهایش از همهٔ پروفایل‌ها حذف می‌شوند. اتصال‌های باز می‌مانند. |

برای **همین سرور**، کلید، آدرس، پورت و **فعال** نشان داده نمی‌شوند.

## ضریب مصرف

ضریب تعیین می‌کند ترافیک یک نود چقدر از سهمیهٔ کاربر مصرف کند.

| ضریب | ۱ گیگابایت مصرف روی نود چقدر حساب می‌شود |
|---|---|
| ۱ | ۱ گیگابایت |
| ۱٫۵ | ۱٫۵ گیگابایت |
| ۰٫۵ | ۰٫۵ گیگابایت |
| ۰ | هیچ |

با آن می‌توانید ترافیک یک مسیر گران را گران‌تر یا یک مسیر رایگان را بی‌هزینه حساب کنید. ترافیکی که روی کارت، در **ترافیک واقعی**، می‌بینید همیشه مقدار واقعی است. صفحهٔ اشتراک ضریب را کنار هر اینباند نشان می‌دهد.

## آدرس‌های اتصال و سرورهای واسط

به‌طور پیش‌فرض کاربران به آدرس خود نود وصل می‌شوند. اگر یک سرور واسط یا تونل جلوی نود است، آدرسش را زیر **آدرس‌های اتصال** اضافه کنید تا پروفایل‌هایی که کاربران دانلود می‌کنند به آن اشاره کنند.

| فیلد | چه کار می‌کند |
|---|---|
| **برچسب** | نامی برای آدرس، مثلاً `Tehran relay`. |
| **آدرس** | دامنه یا آی‌پی سرور واسط. |
| **پورت** | خالی یعنی پورت خود اینباند. اگر نود چند اینباند دارد، پورت متفاوت باید با یک اینباند مشخص زیر **برای** بیاید. |
| **برای** | **همهٔ اینباندها**، یا یک اینباند از این نود. |

هر آدرس یک پروفایل جدا برای کاربران می‌شود، و در پروفایل «همه در یک فایل» هم یک خط `remote` می‌گیرد. می‌توانید تا ۳۲ آدرس برای هر نود اضافه کنید.

افزودن آدرس اتصال فقط چیزی را که پروفایل‌ها اعلام می‌کنند تغییر می‌دهد. سرور واسط را راه نمی‌اندازد. واسط یا تونل را خودتان باید تنظیم کنید.

::: warning
وقتی نودی آدرس اتصال دارد، پروفایل‌ها فقط از همان‌ها استفاده می‌کنند. اگر کاربران ممکن است مستقیم هم وصل شوند، آدرس خود نود را هم یکی از آن‌ها کنید، وگرنه اتصال مستقیم از پروفایل‌ها ناپدید می‌شود.
:::

## حذف نود

**بیشتر ← حذف نود** تأیید می‌خواهد. اینباندهای نود متوقف می‌شوند و به **بدون نود** می‌روند و کاربران دسترسی‌شان را نگه می‌دارند. نرم‌افزار روی سرور نصب می‌ماند؛ آنجا با `ovira uninstall` حذفش کنید ([حذف اویرا](/fa/start/uninstall)). برای اجرای دوبارهٔ اینباندها آن‌ها را به نود دیگری متصل کنید.
