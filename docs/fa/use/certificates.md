# گواهی‌ها

صفحهٔ **گواهی‌ها** همهٔ گواهی‌هایی را که اویرا استفاده می‌کند فهرست می‌کند: گواهی HTTPS پنل و گواهی پشت هر اینباند OpenConnect و IKEv2، با نوع، اینباندهایی که از آن استفاده می‌کنند، تاریخ انقضا و اینکه خودش تمدید می‌شود یا نه.

## نوع‌ها

| نوع | چیست |
|---|---|
| **گواهی پنل** | گواهی HTTPS پنل که هنگام نصب یا با `ovira ssl` تنظیم می‌شود. [HTTPS برای پنل](/fa/start/https) را ببینید. |
| **Let's Encrypt** | گواهی عمومی برای دامنه یا آدرس IPv4 یک نود. دستگاه‌ها بدون نصب چیزی به آن اعتماد دارند. |
| **Ovira CA** | گواهی امضاشده با CA خود پنل شما. رایگان و خودکار، اما دستگاه‌ها باید یک بار CA را معتبر کنند. |

## گرفتن گواهی Let's Encrypt برای یک نود

1. به **گواهی‌ها** بروید و **گواهی جدید** را بزنید.
2. **نود** را انتخاب کنید. نودی که *نیاز به به‌روزرسانی* دارد باید اول به اویرا ۱٫۰ به‌روز شود.
3. دامنه‌ای که به آن نود اشاره می‌کند را وارد کنید، یا **نام یا آدرس** را خالی بگذارید تا آدرس IPv4 نود استفاده شود. گواهی‌های IP کوتاه‌مدت‌اند و خودکار تمدید می‌شوند.
4. **درخواست گواهی** را بزنید. نود ظرف یکی دو دقیقه آن را صادر می‌کند؛ وضعیت از **در حال صدور** به **معتبر** می‌رسد.

بعد گواهی را در یک اینباند OpenConnect یا IKEv2 روی همان نود انتخاب کنید. هنگام ویرایش اینباند، گواهی‌های موجود روی نودش پیشنهاد می‌شوند.

::: tip پورت ۸۰
Let's Encrypt برای صدور و هر تمدید به پورت TCP ۸۰ آزاد و باز روی نود نیاز دارد (یا پورت ۴۴۳ تا وقتی اینباندی که از آن استفاده می‌کند هنوز اجرا نشده).
:::

## سرور اصلی

سرور اصلی هم مثل هر نود دیگری می‌تواند از همین صفحه گواهی Let's Encrypt بگیرد. اینباندهای **همین سرور** می‌توانند از آن استفاده کنند و تنظیمات HTTPS پنل آن را با نام **گواهی سرور اصلی** نشان می‌دهد: آنجا انتخابش کنید و پنل را دوباره راه بیندازید. تمدیدها خودکار اعمال می‌شوند.

## تمدید

گواهی‌های Let's Encrypt پیش از انقضا خودشان تمدید می‌شوند؛ **تمدید همین حالا** بلافاصله تمدید را شروع می‌کند. گواهی‌های تمدیدشده بدون قطع کاربران متصل به سرورهای IKEv2 در حال اجرا می‌رسند. اگر تمدید شکست بخورد، وضعیت **تمدید ناموفق** می‌شود و اینباند آخرین گواهی معتبر را نگه می‌دارد یا به گواهی اویرا برمی‌گردد (**استفاده از گواهی اویرا**).

## حذف گواهی

گواهی وقتی قابل حذف است که هیچ اینباندی از آن استفاده نکند؛ صفحه اینباندهایی را که باید اول عوض شوند نام می‌برد. نود فایل‌هایش را پاک می‌کند و بعداً می‌توانید دوباره درخواستش کنید.
